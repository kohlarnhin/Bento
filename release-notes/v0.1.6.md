新功能
- 项目支持分组、置顶和归档，可拖动调整组内顺序、跨组移动项目和调整分组顺序；分组支持重命名、折叠和删除
- 按 ⌘P 打开快速切换面板，按名称、路径或端口搜索项目（含已归档项目），并可直接启停项目、新建终端、添加项目或分组
- 终端支持 ⌘F 查找内容、⌘G / ⌘⇧G 切换匹配，⌘+ / ⌘- 调整字号，⌘0 恢复默认；程序标题显示在终端名称旁
- 按 ⌘⇧U 跳到最近需要处理的终端，依次查看各终端的提醒
- 添加项目时扫描更多框架配置、环境文件、启动脚本和 Compose 端口，候选端口显示来源并可点击填入；端口冲突时可查看占用进程并选择建议端口

修复
- 修改项目目录后，提醒已打开的终端仍在原目录，可在侧边栏重启
- 新建和编辑项目时统一检查端口重复，避免旧配置和命令行修改继续保留重复端口

改进
- 默认使用紧凑侧边栏，显示项目头像、状态和端口，仅展开当前项目；可在设置中切换，另可按运行中、提醒或 Git 改动筛选项目
- 拖入文件夹时显示名称和识别提示，对重复目录、无效路径和一次拖入多项给出明确提示
- 优化运行状态检查、日志更新和 Git 信息刷新，减少后台开销与界面刷新
