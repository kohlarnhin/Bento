新功能
- 一个项目可管理多个服务。重新扫描可以识别子目录中的服务和根目录启动脚本，并预览变更。启动和停止统一管理整个进程树，打开网页时可选择服务。
- Bento 启动标准为单服务注入 `PORT`，为多服务额外提供 `BENTO_PORT_WEB`、`BENTO_PORT_API` 等角色端口以及 `BENTO_PORTS`。概览和重新扫描会提示脚本缺少哪些端口变量，编辑项目时可预览并生成 `scripts/bento-dev.sh`。
- 概览显示各服务的监听与 HTTP 健康状态、CPU 和内存曲线。启动日志支持按服务或问题筛选，并可跳到最近的错误。
- 概览展示 Git 改动和分支状态，提供更换端口及经确认释放占用端口的入口。项目停止后可查看上次运行的时长、退出状态和释放的端口。

修复
- 窄窗口的资源区横跨两列，并为日志保留足够的可视高度。
- 项目停止后仍打开的交互终端用灰点标记，区分终端会话与项目运行状态。

改进
- 优化侧栏项目与终端行的间距、选中效果和筛选切换动画，统一运行中计数。
- 窗口主题跟随系统。
