新功能
- AI 会话感知：侧栏、终端标签、底栏和菜单栏会显示 Claude Code / Codex 是在运行、等你回复还是已经完成。⌘⇧U 跳到需要你处理的会话，完成时会发通知。
- 继续之前的 AI 会话：「＋」菜单列出这个项目的 Claude / Codex 历史会话，点一下就能继续，也可以直接新建 Claude 或 Codex 会话。重启后终端里会出现「继续会话」卡片，侧栏会显示可以继续的会话数。
- ⌘P 可以跨项目搜索 AI 会话，回车直接继续。支持拼音全拼和首字母，比如输入 sxtj 就能找到「筛选条件」。
- 终端会话恢复：重启 Bento 后恢复终端标签、目录和输出。
- 常用命令：在终端底部保存常用命令，点一下就运行。
- 命令完成提醒：耗时较长的命令跑完后会通知你。
- 菜单栏面板：不打开主窗口，也能在菜单栏查看项目状态。
- 侧栏新增右键菜单。

改进
- 侧栏筛选不再出现重复项；按服务实际监听的端口判断运行状态。
- 会话列表隐藏只问了一句、不到一分钟且没改过文件的会话。会话标题会去掉自动注入的内容和粘贴的日志。
- 会话列表会缓存，重启后 ⌘P 立即就有结果。恢复多个终端标签时只先加载当前标签，启动更快。
- 滚动条改为更细、只在滚动时出现的样式。

修复
- 切换项目时终端不再闪白。
- ⌘P 分组的外框线条不再断开。
